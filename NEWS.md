# radar.raman 0.1.0

* Integrates the full test suite with testthat and RStudio Test Package.

* Standalone R implementation of spectral decomposition, synthetic generation,
  automatic differentiation, Adam training and evaluation.
* Includes pretrained standard and ensemble models as native R objects.
* Spectral file readers and writers, map operations and an Rscript interface.
* Comprehensive vignette with executable R examples and API reference.
